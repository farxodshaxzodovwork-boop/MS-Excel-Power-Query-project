# MS-Excel-Power-Query-project
Ushbu Power Query project Marketpleysda savdo qiluvchi dokonning "Summer Sales" hisoboti ya'ni 2025-yilning Iyun, Iyul va Avgust oylarining savdosi

Marketpleys tizimida har oy uchun alohida yuklab olingan savdo hisobot fayli bor edi men ularni bitta "Summer Sales" papkasiga joylashtirib MS Exceldagi Power Query vositasidan foydalanib ularni:
- birlashtirdim
- sana va holat ustunlarini tozaladim va formatladim
-  yaratilish va olinish oralig'idagi kunlar sonini aniqladim
-   dona narxi va dona tannarxi larini aniqladim
-   komisiya va logistika xarajatlarini qo'shib jami marketpleys ulushini aniqladim
-   daromaddan marketpleys ulushini ayirib chiqarilgan pul miqdori ya'ni tushumni aniqladim
-   tushumdan esa jami tannarxni ayirib esa Sof Foydani aniqladim
-   hamda ushbu Power Query bo'limida bajargan ammallarimni Close&Load qilib Sheet ga tushurib oldim
-   undan keyin esa ularni Pivot Table da tahlil qildim
-   Pivot Table dagi tahlillarni chartlarga vizuallashtirdim
